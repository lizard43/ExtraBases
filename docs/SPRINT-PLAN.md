# Sprint plan: original toolchain gate

This is a starting governance plan, not a replacement for existing project-specific planning elsewhere. Every sprint must inventory original source/toolchain/runtime; establish a complete native original-style source load/build; trace and preserve original routines/DATA; implement only authorized target-hardware adapters; execute native compilation, output checks, emulator and hardware tests as separate gates; record open work and approvals in TECHNICAL-DEBT.md. STOP before any unapproved alternative. See ENGINEERING-RULES.md at repository root.
